1) SYSTEMUEBERBLICK
============================================================
- Framework: Laravel 12
- Schwerpunkt: News-/Medienportal mit Admin-Backoffice, Versand, Delivery-Tracking und Abrechnung
- Rollen/Rechte:
  - access_admin: Zugriff auf /admin
  - view_customer_area: Zugriff auf /kunden
- Hauptmodule:
  - Oeffentliche News-Seiten
  - Admin-News-Redaktion inkl. Medienverwaltung

============================================================
2) OEFFENTLICHE FUNKTIONEN
============================================================
Routen (web):
- GET /                                -> NewsController@index
- GET /news/{slug}                     -> NewsController@show
- GET /robots.txt                      -> SitemapController@robots
- GET /sitemap.xml                     -> SitemapController@index
- GET /sitemap-news.xml                -> SitemapController@newsSitemap
- GET /d/{token}                       -> DeliveryController@show
- POST /d/{token}/confirm              -> DeliveryController@confirm
- GET /d/{token}/m/{media}             -> DeliveryController@download

Features:
- News-Liste mit Suche ueber q-Parameter
- Artikel-Detailseite mit SEO-Meta, OG, JSON-LD, Galerie/Lightbox
- Canonical-/Robots-Logik im Frontend-Layout + X-Robots-Header per Middleware
- Sitemap + Google-News-Sitemap
- Signed-Delivery-Links mit Ablauf/Widerruf, Downloadtracking und Aktivitaetsprotokoll
- Medienpaket-Download (/d/{token}/m/{media}): Auslieferung verbindlich der Originaldatei
  (news_item_media.path), nicht Preview/Thumb/Poster/Redaction; Vorschau in der UI bleibt
  getrennt (public_url / preview_url). Logik: NewsItemMedia::resolveDeliveryDownloadRelativePath()

============================================================
7) DISTRIBUTIONSWEG (END-TO-END)
============================================================
1. Erfassung
   - Redaktion erstellt News in /admin/news/create
   - Felder: Titel, Teaser/Subheadline, Body, Region/Ort, Status, publiziert/Embargo

2. Medienaufnahme und Aufbereitung
   - Upload von Bild/Video/Audio pro News
   - Speicherpfade NEUER Uploads (seit Umstellung): strukturiert unter
     news-media/YYYY/MM/DD/{artikel-slug}/ bzw. .../derived/ fuer abgeleitete Dateien
     (Preview, Thumb, Poster, Redaction-Backups etc.); Altbestaende unveraendert lesbar
     (Legacy-Pfade). Zentrale Logik: App\Services\MediaStorage (generateMediaPath /
     generateDerivedMediaPath). Doku: docs/media-storage-structure.md
   - Medienattribute (sichtbar/versand/teaser/caption)
   - Bild- und Video-Metadatenjobs
   - Optional Redaction (Kennzeichen/Gesichter/Regionen)

3. Freigabe und Publikation
   - Status auf published, zeitliche Sichtbarkeit ueber published_at/embargo_at
   - Oeffentliche Ausspielung:
     - Liste: /
     - Detail: /news/{slug}
   - SEO-Ausspielung in Sitemap + Sitemap-News

4. Distribution (B2B-Auslieferung)
   - E-Mail-Distribution:
     - Empfaenger ueber DeliveryDestination und/oder Kontakt
     - Signierter 48h-Link auf /d/{token}
   - FTP/SFTP-Distribution:
     - UploadRun mit DeliveryRun + DeliveryRunItems

5. Empfaengerfluss
   - Empfaenger oeffnet Delivery-Link
   - optional Confirm-Schritt
   - Download einzelner Medien ueber signierte Download-URL (Originalmedium path;
     keine Wasserzeichen-Vorschau als Download)
   - Events werden protokolliert (opened/confirmed/downloaded)

6. Monetarisierung / Nachverfolgung
   - Nutzungseintraege in Backoffice Usage
   - Aggregation in Billing (Rechnungsentwuerfe)
   - Versand finaler Rechnung inkl. Exportformaten

7. Betrieb / Sicherheit
   - Cron + Queue Heartbeat
   - Backup (manuell + geplant)
   - noindex fuer interne Bereiche, indexierbar fuer public content

============================================================
8) SEO- UND URL-LOGIK (AKTUELL)
============================================================
- Canonical: global normalisiert (https, query-frei)
- Robots:
  - index,follow fuer relevante Seiten
  - noindex,follow fuer Such-/Parameterseiten
  - noindex,nofollow fuer Admin/Auth/Delivery/System
- Slug-Handling:
  - /news/{slug} mit Sichtbarkeitspruefung
  - Redirect-Tabelle news_slug_redirects fuer alte Slugs (301) / gone (410)
