4) REDACTION-SUBSYSTEM (BILDER) - AKTUELLER IST-STAND
============================================================
- Pipeline:
  ProcessMediaRedaction (Laravel) -> detect_and_redact.py (Python) -> redacted Datei.
- Statusmodell:
  pending / done / failed / disabled / legacy(null)
- Fail-safe:
  Bei pending/failed keine ungeschuetzte oeffentliche Original-Auslieferung.

4.1) Umgesetzte Aenderungen (global)
- detect_and_redact.py wurde minimal und rueckwaertskompatibel gepatcht:
  - PATCH: reduce false positives on uniform text
  - strengere Plausibilitaet fuer Kennzeichen-Boxen
  - Blur mit leichtem Inset (weniger Rand-/Nachbartexttreffer)
  - optionaler OCR-Whitelist-Pfad fuer Woerter wie POLIZEI/FEUERWEHR
  - OCR-loser Heuristik-Fallback aktiv, falls OCR-Stack fehlt
- Outputformat fuer Laravel blieb unveraendert kompatibel.

4.2) Laufzeitstatus OCR auf aktuellem Server
- pytesseract: nicht installiert
- tesseract binary: nicht vorhanden
- Folge:
  OCR-Wortausnahme ist vorbereitet, aber derzeit nicht aktiv.
  Aktuell wirkt der Non-OCR-Fallback (Heuristikpfad).

4.3) Bestandsdaten
- Bereits erzeugte redacted-Dateien bleiben bestehen.
- Neue Logik greift erst bei erneuter Redaction je Medium.
- Deshalb sind Reprocess-Laeufe fuer Altbestaende notwendig.
