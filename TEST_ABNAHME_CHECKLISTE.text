B) Basis / Deployment
--------------------------------------------------------------------------------
  [ ] APP_URL in .env = öffentliche HTTPS-URL der Seite
  [ ] php artisan config:clear && php artisan config:cache (nach .env-Änderung)
  [ ] php artisan route:cache (optional, nach Route-Änderungen)
  [ ] Queue-Worker läuft (falls Jobs/AI/Redaction/Upload-Pipeline): 
        php artisan queue:work (oder Supervisor/systemd)
  [ ] Cron für Laravel Scheduler (falls genutzt): * * * * * php artisan schedule:run

--------------------------------------------------------------------------------
C) Öffentliche Website (ohne Login)
--------------------------------------------------------------------------------
  [ ] Startseite / lädt, keine 500er-Fehler
  [ ] News-Liste: Meldungen sichtbar, Teaser-Bilder laden (S3 oder /storage)
  [ ] Einzelne News-URL /news/{slug}: Text, Bilder, Video/Audio wie erwartet
  [ ] Canonical / Meta robots plausibel (Seitenquelltext kurz prüfen)
  [ ] robots.txt / sitemap.xml erreichbar (falls aktiv)

D) Anmeldung & Rechte
--------------------------------------------------------------------------------
  [ ] Login mit lokalem Konto (E-Mail + Passwort)
  [ ] Optional: „Mit Microsoft anmelden“ (falls genutzt)
  [ ] Geschützte Admin-URL ohne Login → Redirect zur Anmeldung

E) Admin – Nachrichten (News)
--------------------------------------------------------------------------------
  [ ] /admin/news – Liste lädt ohne Fehler

  [ ] Einzelnes Medium löschen (falls vorhanden) – Dateien in S3 entfernt
